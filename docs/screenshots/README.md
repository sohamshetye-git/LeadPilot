# Screenshots Directory

Save clean product screenshots in this directory with the following filenames:

- `dashboard.png` - Main Executive Dashboard view showing lead pipeline metrics and upcoming actions.
- `leads.png` - Lead Directory table view with search, status filters, and priority badges.
- `lead-intelligence.png` - Lead Detail page showing AI Summary, AI Scoring, and Pre-Contact Brief.
- `follow-up.png` - Lead Detail follow-up generator with personalized tone & purpose selections.
- `analytics.png` - Event Performance Analytics page showing conversion and event yield breakdowns.
